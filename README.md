# 🏠 Airbnb Hotels Data Analysis

An interactive Power BI dashboard analyzing Airbnb listings, covering pricing, ratings, room types, property types and neighbourhood performance with dynamic slicers for data-driven insights.

## 📌 Project Overview
This project explores Airbnb listing data to understand pricing patterns, guest ratings, review activity and how different neighbourhoods, room types and property types perform. The dashboard helps hosts, analysts and travellers make better decisions.

## 📊 Key Metrics (KPI Cards)
- Total Listings
- Total Reviews
- Average Price
- Average Rating
- Unique Neighbourhoods

## 📈 Visualizations
- **Pie Chart:** Distribution of listings by Room Type
- **Column Chart:** Listings by Neighbourhood
- **Combo Chart (Line + Column):** Neighbourhood vs Price
- **Line Chart:** Price trend by Property Type

## 🎛️ Interactive Filters (Slicers)
- Neighbourhood
- Property Type
- Room Type
- Price

## 🛠️ Tools & Techniques
- Power BI Desktop
- Data modeling and cleaning
- DAX measures
- Interactive dashboard design

## 📁 How to Use
1. Download `airbnb.pbix` from this repository.
2. Open it in **Power BI Desktop** (free to download from Microsoft).
3. Use the slicers to filter and explore the data.
